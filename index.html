01 / BUSINESS STRATEGY

핵심 사업은 유지하고, 초기 시스템은 가볍게.

03 / OPERATION

전용 관리자 화면 없이 운영하는 방법

공개용 업체 데이터는 운영자 전용 Google Sheets에서 관리합니다. 신청·문의 정보는 별도의 비공개 시트로 분리합니다. 웹사이트는 승인된 공개 항목만 읽습니다.

입점 신청

업체가 기본 정보, 소개, 이미지 URL, 홈페이지 및 패키지 링크를 입력하면 비공개 신청 시트에 접수됩니다.

검토 및 승인

운영자가 신청 내용을 확인하고 유료 업체는 입금 확인 후 공개용 시트에 등록합니다. 노출 여부 Y/N으로 관리합니다.

업체 노출

사이트에서 승인된 카드만 표시합니다. 시트 수정은 캐시 갱신 후 반영되며 실시간 양방향 동기화는 제공하지 않습니다.

견적 요청

여행객이 업체와 요청사항을 선택해 문의하면 운영자 전용 시트에 기록됩니다. 운영자가 해당 업체에 직접 전달합니다.

입점 기간

1·3·6·12개월 상품 정책과 만료일을 시트에서 수동 관리하며, 만료 시 운영자가 노출을 해제합니다.

성과 확인

GA4 기본 방문 통계를 확인할 수 있습니다. 입점사별 월간 자동 보고서는 별도 개발 대상입니다.

별도 VPS 및 Wix 구독 없이 시작하는 구조입니다. 무료 할당량 또는 기본 운영 범위를 초과할 경우 유료 플랜과 증설 비용은 별도 협의합니다. 실제 서비스 배포는 API 계정과 권한 확인 후 확정합니다.

자주 묻는 질문

기존 Wix 사이트를 그대로 수정하는 방식인가요?

아닙니다. 신규 독립형 웹사이트 구축 제안이며 기존 Wix의 회원·CMS 데이터 이전은 포함하지 않습니다.

AI가 실시간 여행 정보를 제공하나요?

Gemini 기반 추천과 일정 생성입니다. 실시간 관광공사·Places 데이터 검증은 후속 개발 범위입니다.

입점비를 받을 수 있나요?

가능합니다. 운영자가 계좌이체를 확인하고 승인하는 수동 운영 방식이며 자동 결제는 별도입니다.

추가 기능이 필요한 경우 어떻게 하나요?

사업 운영 결과를 바탕으로 범위와 비용을 협의해 단계적으로 추가합니다.
